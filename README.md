# Financial Calories

الرجيم المالي الذكي: سعرات مالية أسبوعية توصلك لهدف ادخارك.

تطبيق ويب يحسب لك ميزانية أسبوعية مرنة (السعرات المالية) من راتبك وفئات صرفك، ويتوقع صرفك الشهري بنموذج ذكاء اصطناعي (XGBoost) يشتغل داخل المتصفح.

## المميزات
- الشهر يبدأ من يوم نزول الراتب، والميزانيات تتجدد معه.
- المستخدم يختار فئاته ويحدد ميزانية كل فئة.
- سعرات مالية أسبوعية في الصفحة الرئيسية.
- لصق رسائل البنك النصية لاستخراج المبلغ والمتجر والتاريخ.
- توقع صرف الشهر لكل فئة بنموذج XGBoost مدرّب على بيانات Consumer Expenditure Survey (BLS).
- نسخة احتياطية بكود نصي لنقل البيانات بين الأجهزة.

## الخصوصية
كل البيانات تنحفظ في متصفح المستخدم فقط (localStorage)، وما فيه أي خادم يستقبل بيانات.

## ملاحظة
النموذج متدرّب على بيانات إنفاق أسر أمريكية، فالتوقعات تقريبية وليست استشارة مالية.

## الملفات
| الملف | الوظيفة |
